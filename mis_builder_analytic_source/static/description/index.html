MIS Builder Analytic Source

Since Odoo 16 a journal item no longer has one analytic account: it has an analytic_distribution that can split it between several accounts. The analytic filter of a MIS report on journal items keeps the full balance of every item whose distribution contains the analytic account, so a P&L per project, contract or department is overstated whenever an item is split. Costs that only exist as analytic lines, such as timesheets, are not seen at all.

This module adds mis.analytic.move.line, a SQL view over account.analytic.line with the fields MIS Builder expects from a move lines source (account_id, company_id, date, debit, credit, parent_state, analytic_distribution). Analytic lines already carry the prorated amount, so a MIS report that uses this model as its move lines source gives the exact figures per analytic account, including timesheet costs.

Each analytic line holds one account per root analytic plan. The view exposes them as one distribution key ("project_account,department_account" at 100%), the same format as journal items, so the analytic filter works for the accounts of every plan and a line is never counted twice.

Configuration

Analytic lines without a financial account (timesheets, manual analytic entries) are reported on the company’s MIS Analytic Fallback Account (Invoicing > Configuration > Settings, Analytics section). When it is not set, the first Cost of Revenue account of the company (by code) is used.

Usage

  1. In the MIS report template, set Move lines source to Analytic line as MIS move line.
  2. Use the analytic filter of the report instance, or an analytic domain per column.
  3. Expressions can also filter on the origin of the line, for example balp[5%][('line_origin', '=', 'timesheet')] or -balp[6%][('category', '=', 'invoice')].

The sign follows journal items: a positive analytic amount (revenue) is a credit and a negative one (cost) is a debit, so the usual -balp[...] expressions for income keep working.

Known issues / Roadmap

  • Analytic lines are always in the company currency; amounts in another currency are not converted.
  • Draft journal items have no analytic lines, so the posted and draft target move option shows the same figures as posted only. Manual analytic entries and timesheets count as posted.
  • The view is rebuilt when an analytic plan is created, moved or deleted, because each root plan is a column of the analytic lines.
