- Analytic lines are always in the company currency; amounts in another currency
  are not converted.
- Draft journal items have no analytic lines, so the *posted and draft* target move
  option shows the same figures as *posted only*. Manual analytic entries and
  timesheets count as posted.
- The view is rebuilt when an analytic plan is created, moved or deleted, because
  each root plan is a column of the analytic lines.
